# Data

This repository does not commit the large source dataset or generated analysis tables.

- `raw/` — CellRank's public `bone_marrow.h5ad`, downloaded on first analysis run.
- `processed/` — dashboard-ready Parquet/JSON files generated by `scripts/prepare_data.py`.

Run:

```bash
python scripts/prepare_data.py
```

The source dataset is early human hematopoiesis (CD34+ bone-marrow cells) exposed by `cellrank.datasets.bone_marrow()`.
